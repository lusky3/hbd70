## Task Description

Implement a global/family arcade leaderboard backend and in-game UI using Cloudflare Workers + Cloudflare D1 (serverless SQLite):
1. Create a serverless Cloudflare Worker API with D1 database schema (`leaderboards` table).
2. Endpoints for submitting scores (`POST /api/v1/leaderboard/:gameId`) with 3-letter initials, anti-tamper validation, and rate limiting.
3. Endpoints for querying top 10 scores (`GET /api/v1/leaderboard/:gameId`) for all 4 arcade games (Tanks, Pong, Space Invaders, Asteroids).
4. Integrate a Phaser 3 arcade high-score initials entry spinner and leaderboard modal with graceful offline fallback to `localStorage`.

## Security Findings

- Parameterized SQL Queries: D1 bindings prevent all SQL injection attacks.
- Initials Sanitization: Strict regex `[^A-Z0-9 !?★]` and uppercase 3-char bounding.
- Rate Limiting: In-worker sliding window IP limiter throttles abuse (max 15 req/min/IP).
- Score Bounds: Per-game plausible thresholds (Pong 1k, Tanks 300k, Invaders 500k, Asteroids 2M).
- XSS Prevention: Direct HTML5 canvas text rendering without DOM manipulation.
- Fail-Soft Offline Fallback: 3000ms AbortController timeout prevents UI locking.
