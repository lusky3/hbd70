## Phase Summary

- bootstrap: Classified as quick-win. Root cause identified: container.setSize(w, h) and container.setInteractive() create a hitArea at (0, 0, w, h) relative to the container origin, whereas button visuals and labels are drawn centered around (0, 0) or offset in Y (-18 to +18). This leaves the entire top half or top-left quadrant without a hotspot.
- plan: MFR documented; plan artifact created in back_button_and_controls_hotspot_plan.md specifying centered Phaser.GameObjects.Zone instances across GameSelect, Credits, LevelSelect, Pong, SpaceInvaders, Asteroids, and LeaderboardModal.
- implement: Replaced container setSize/setInteractive with centered Phaser.GameObjects.Zone instances across GameSelect, Credits, LevelSelect, Pong, SpaceInvaders, Asteroids, LeaderboardModal, and Splash; bumped version to 1.4.2 in package.json, version.js, and CHANGELOG.md.
- ship: 91/91 node unit tests passed, dual-browser multiplayer E2E passed, full arcade E2E regression passed with 0 console errors.
