## Known Risk

- Network latency & jitter: Mobile cellular/Wi-Fi packet delays. Requires dead reckoning, client prediction, or lightweight state broadcast (15-20 Hz) with host arbitration.
- Connection drop / reconnection: Players locking screen or switching apps must not crash room or freeze other clients.
- NAT / Firewall traversal: Peer-to-peer WebRTC direct connections can fail behind symmetric mobile carrier NATs without TURN servers. WebSocket relay or Cloudflare Durable Object room routing provides guaranteed 100% connectivity.

---

## Decisions

- [architecture][2026-09-22][main] WebRTC P2P DataChannels via PeerJS: $0 infrastructure cost using Google public STUN; eliminates dedicated server maintenance.
- [gameplay][2026-09-22][main] Host-authoritative simulation with client prediction and remote lerp interpolation at 25-30 Hz.
- [ux][2026-09-22][main] 4-character room codes with Canvas QR code camera scanning for frictionless mobile auto-join via ?room=XXXX.
- [gameplay][2026-09-22][main] Pong perspective inversion gives both competitors ergonomic bottom under-paddle touch grip controls.
