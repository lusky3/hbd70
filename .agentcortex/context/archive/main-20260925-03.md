## Known Risk

- Stale session recovery on app updates. Mitigation: Session payload includes version and timestamps; invalid or outdated sessions are safely cleared.
- Rollback Plan: `git revert <commit-sha>` cleanly restores previous scene launch behavior. Operators verify rollback via `tests/e2e_arcade_verification.py`.

---

## Decisions

### D-1: Per-Game Isolated Session Keys → local
- Decision: Use dedicated `hbd70_session_<gameId>` keys rather than a single monolith session blob.
- Reason: Prevents cross-game state corruption and ensures independent resume capabilities.

### D-2: Dual Lifecycle & Checkpoint Auto-Save → local
- Decision: Combine browser lifecycle hooks (`visibilitychange`, `pagehide`) with in-game checkpoint triggers.
- Reason: Guarantees zero progress loss on mobile app switches and abrupt browser termination.
