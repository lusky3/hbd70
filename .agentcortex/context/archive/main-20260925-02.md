## Known Risk

- Ball tunneling/clipping at high strike velocities. Mitigation: 4 sub-steps per frame in `PoolPhysics.js` with continuous collision resolution.
- Turn desync in multiplayer. Mitigation: Host is sole authoritative physics simulator; clients stream shot parameters and receive ball position snapshots.
- Rollback Plan: `git revert <commit-sha>` cleanly removes pool game scenes, physics/rules engines, assets, and leaderboards without impacting existing retro games or scores. Operators verify rollback via `tests/e2e_arcade_verification.py`.

---

## Decisions

### D-1: Custom 2D Sub-Step Billiard Physics Engine → local
- Decision: Build a dedicated custom physics solver `PoolPhysics.js` instead of generic Arcade physics boxes.
- Reason: Pool requires exact circle-circle elastic collision impulse exchange, tangent/normal decomposition, and rail restitution.

### D-2: 4 Independent Subtype Leaderboards → local
- Decision: Create separate leaderboards `pool_8ball`, `pool_9ball`, `pool_straight`, and `pool_speed`.
- Reason: Rules and scoring mechanics differ substantially across formats.
